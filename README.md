# 🧰 Workflow Toolkit

A Blender addon that gathers everyday cleanup, geometry and organization tasks into one sidebar panel, so you can tidy a scene in a few clicks instead of digging through menus.

**Location:** 3D View → Sidebar (N) → **Toolkit**
**Version:** 1.1.0 · **Author:** Hiro

## Features

### 🔧 Modifiers and Geometry
- **Apply Modifiers**: applies every modifier on the selected objects
- **Remove Modifiers and Constraints**: strips all modifiers and constraints
- **Triangulate Mesh** / **Convert to Quads**
- **Merge by Distance**: removes duplicate vertices
- **Recalculate Normals**: fixes odd shading
- **Origin to Geometry**: centers the origin on the mesh
- **Align to Z Axis**: drops the selected objects onto Z = 0

### 🧼 Cleanup and Optimization
- **Remove Unused Materials**
- **Remove Hidden/Empty** objects with no geometry
- **Clear Scene**: deletes every object in the scene
- **Clear Cache**: empties Blender's temporary folder
- **Optimize Viewport**: lowers subdivision, shadows and overlays for smoother navigation

### 📦 Organization and Renaming
- **Sequential Rename** and **Rename with Prefix**
- **Group Selected into Collection**
- **Group by Type**: sorts objects into collections by type

## Installation

1. Download `Toolkit_EN.py` from this repository.
2. In Blender: **Edit → Preferences → Add-ons → ∨ → Install from Disk…**
3. Select the file and enable **Workflow Toolkit**.
